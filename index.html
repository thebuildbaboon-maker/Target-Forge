Browser-enforced base rules

The RePoE candidate index is filtered again in this site using base tags, item class, modifier domain, ordered spawn weights and explicit source mappings. Base-incompatible modifiers never enter the selectable list.

Load directly

Fetches current PoE 1 exports from RePoE. This works when the files are served over HTTP and the source allows cross-origin requests.

Import downloaded files

Select base_items.min.json, mods.min.json, and mods_by_base.min.json. You may also include stat translations, crafting-bench options, essences and item classes. Unknown optional files are ignored.
